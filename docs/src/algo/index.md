# 数据结构与算法

## 一、简介

数据结构是数据在内存中的组织、存储方式，直接决定了对数据的访问效率和修改成本。算法是解决特定问题的有限、确定、可执行步骤的集合，其优劣通过时间复杂度和空间复杂度来度量。常见结构如数组、链表、栈、队列、树、哈希表、图等，配合查找、排序、遍历、递归、动态规划等算法，构成了程序效率的根基。
